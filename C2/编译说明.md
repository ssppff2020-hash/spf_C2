# 编译说明

> 怎么把 `paper.tex` 编成 `paper.pdf`。两种路径：**一条命令**，或**手动四步**。

---

## 一、最快的路径（推荐）

```bash
cd C2
bash pipeline/05_build.sh
```

它会依次跑 `pdflatex → bibtex → pdflatex → pdflatex`，
拷贝 `paper.tex` / `references.bib` / `figures/` 到 `build/`，
把完整日志写到 `build/build.log`，最后做五类健全性检查：

- 未定义交叉引用
- 未定义引文
- 未定义控制序列
- Emergency stop
- 找不到文件

**任何一类出现即以退出码 1 失败**，不会静默通过。

脚本会自己找 TeX Live（依次尝试
`~/texlive/2026/bin/windows`、`/c/texlive/2026/bin/windows`、`/c/texlive/2024/bin/windows`）。

预期输出：

```
[build] pdflatex#1=0 bibtex=0 pdflatex#3=0
[build] paper.pdf: 15 pages, 455613 bytes
[build] OK -- no undefined references, citations or control sequences.
```

## 二、手动四步

任何有 `pdflatex` + `bibtex` 的 TeX 发行版（TeX Live / MiKTeX / MacTeX）都可以：

```bash
cd C2
mkdir -p out && cd out
cp ../paper.tex ../references.bib .
cp -r ../figures .

pdflatex -interaction=nonstopmode paper.tex    # 第一趟：生成 .aux
bibtex   paper                                  # 处理参考文献
pdflatex -interaction=nonstopmode paper.tex    # 第二趟：插入引文
pdflatex -interaction=nonstopmode paper.tex    # 第三趟：稳定交叉引用
```

**为什么要四步**：`\cite` 需要 `.aux`，`\ref` 需要第二趟才稳定。
只跑一趟的话引文会显示成 `[?]`，页眉页码也可能不对。

**用 `xelatex` 也可以**（论文不含中文字形依赖，两种引擎都行）：

```bash
xelatex paper.tex && bibtex paper && xelatex paper.tex && xelatex paper.tex
```

## 三、本机没有 LaTeX 怎么办

本机原本没有任何 TeX 发行版。环境搭建已经脚本化：

```bash
python pipeline/00_setup_texlive.py doctor      # 先看看有没有
python pipeline/00_setup_texlive.py install <缺的包>
python pipeline/00_setup_texlive.py refresh     # 修配置 + 建格式 + 建字体映射
```

这个脚本固化了 8 个已知故障的对策，根因写在
[`拿来说明/04-从零装TeXLive-八个故障与根因.md`](拿来说明/04-从零装TeXLive-八个故障与根因.md)。

**注意**：`refresh` 会就地修改 TeX Live 自带的三个 Perl 脚本
（修它们把 PATH 分隔符写死成 `:` 的 bug），原行保留为注释。

## 四、用了哪些宏包

| 用途 | 宏包 |
|---|---|
| 数学 | `amsmath` `amssymb` `amsthm` |
| 表格 | `booktabs` `multirow` `array` `tabularx` |
| 图 | `graphicx`（插图是 PDF，矢量） |
| 颜色/链接 | `xcolor` `hyperref` |
| 参考文献 | `natbib`（`plainnat` 样式） |
| 版式 | `geometry` `microtype` `caption` `titlesec` `enumitem` |
| 字体 | `fontenc`（T1）`inputenc`（utf8）`lmodern` |

都是 TeX Live `scheme-small` 加少数几个常用包里的，普通发行版**开箱即用**。

## 五、图表是生成的，不是手放的

`figures/fig1_assurance_chain.pdf`、`fig2_study_a.pdf`、`fig3_study_b.pdf`
都是 `python pipeline/04_make_figures.py` 生成的。
如果改动了数据，**先重跑那个脚本再编译**，否则图还是旧的。

脚本里**没有任何硬编码的数据常量**——全部从 `pipeline/reports/corpus_audit.json` 读。
所以图与表不可能不一致。

## 六、常见问题

**Q：编译出来引文是 `[?]`。**
A：`bibtex` 那一步没跑，或者 `references.bib` 不在工作目录。
按第二节的顺序跑完整四步。

**Q：报 `I can't find file 'pdflatex.fmt'`。**
A：TeX Live 的格式文件没建。跑 `python pipeline/00_setup_texlive.py refresh`。

**Q：报 `Font ec-lmbx10 ... not found`。**
A：`pdftex.map` 没生成。同样跑 `refresh`（它会调 `updmap`）。

**Q：`bash pipeline/05_build.sh` 说找不到 pdflatex。**
A：脚本找不到 TeX Live。手动指定：

```bash
export PATH="/你的/texlive/2026/bin/windows:$PATH"
bash pipeline/05_build.sh
```

**Q：想换作者名。**
A：改 `paper.tex` 顶部的 `\author{...}` 块。
**注意不要把占位符写成方括号**——`\\[` 在 LaTeX 里是「换行加垂直间距」的可选参数，
会报 `! Missing number, treated as zero.`。源码里有注释提醒。

## 七、验证编译结果

```bash
sha256sum build/paper.pdf references.bib figures/*.pdf
```

与 [`核验/编译验证记录.md`](核验/编译验证记录.md) 里的表对照。

> `paper.pdf` 里内嵌了创建时间戳，**换台机器编译哈希会不同**，这属正常。
> `references.bib` 是内容哈希，应当**逐字节可复现**：
> 跑 `python pipeline/01_verify_refs.py && python pipeline/02_build_bib.py` 验证。
